# Concept thường dùng trong lộ trình

Danh mục chọn các concept hay gặp khi xây ứng dụng Python/Web/AI. Mỗi mục có nghĩa ngắn, tình huống dùng và câu hỏi tự kiểm; không biến tên framework thành bằng chứng đã biết nền tảng.

Học theo [phase và checklist kiến thức](../ROADMAP.md), dùng trang này để tra nghĩa. Các nhóm concept phục vụ nhiều phase nên không nhất thiết trùng với 29 phần kiến thức. Mục `AWARENESS` chỉ cần đạt độ sâu nhận biết đã ghi; `OPTIONAL` là phần mở rộng. Ghi kết quả trong [tracker](../progress/PHASES.md).

## Mức độ học

| Mức | Cần thể hiện |
| --- | --- |
| CORE | Giải thích đúng và áp dụng được trong tình huống cơ bản |
| PRACTICE | Có bài làm, ca lỗi và kết quả kiểm chứng |
| AWARENESS | Phân biệt mục đích, giới hạn và điều kiện lựa chọn |
| OPTIONAL | Chỉ học sâu khi nhánh hoặc dự án cần |

Nhánh ML/DL có CORE/PRACTICE bên trong nhánh, nhưng toàn nhánh vẫn là mở rộng của AI Application. CORE không có nghĩa là tất cả thuật ngữ phải thuộc trước khi bắt đầu làm project.

## Các phân biệt cần nhớ

| Dễ nhầm | Cách phân biệt |
| --- | --- |
| Program / Course / Unit / Topic | Chương trình / khóa / cụm bài / nội dung cụ thể |
| PLO / CLO | Đầu ra program / đầu ra course; có mapping, không có tỷ lệ số lượng cố định |
| Concept / Tool | Nguyên lý có thể chuyển stack / công cụ cụ thể để áp dụng |
| Async / Parallel | Chồng lấn công việc / thực thi đồng thời trên tài nguyên tính toán |
| Authentication / Authorization | Là ai / được phép làm gì trên tài nguyên nào |
| Instruction / Prompt / Context | Quy tắc / yêu cầu tương tác / thông tin đang được cung cấp |
| Memory / Context window | Thông tin lưu dùng về sau / giới hạn thông tin xử lý trong lần gọi |
| Skill / Hook / Tool | Quy trình tái sử dụng / hành động theo sự kiện / giao diện hành động |
| React Hook / Agent hook | Cơ chế React / hook lifecycle của công cụ AI |
| RAG / Fine-tuning | Truy xuất dữ liệu lúc sử dụng / huấn luyện bổ sung tham số |
| Workflow / Agent / Harness | Luồng định trước / model quyết định bước / runtime bao quanh thực thi |
| Retrieval / Reranking | Lấy tập ứng viên / sắp lại tập ứng viên |
| Citation / Support | Có chỉ nguồn / nguồn thật sự hỗ trợ claim |
| Retry / Idempotency | Thử lại / giữ effect đúng contract khi lặp |
| Output / Outcome | Artifact tạo ra / năng lực hoặc thay đổi thể hiện được |
| MLOps / LLMOps / DevOps | Các phạm vi vòng đời có giao nhau; không đồng nhất bằng một dấu bằng |

Bắt đầu từ nhóm gắn với unit đang học. Chọn 3–5 concept, giải thích bằng ví dụ, làm bài rồi ghi vào [review](../templates/REVIEW.md).
