# B1 · Unit 3 · Index và NoSQL

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

EXPLAIN; composite index; document/key-value; TTL; invalidation; cache-aside.

## Bài thực hành

Đo query trước/sau index trên cùng fixture; thêm cache tra cứu địa điểm giả lập và thử khi cache ngừng hoạt động.

## Output cần nộp

Query plan và ADR SQL/NoSQL/cache.

## Tiêu chí kiểm tra

Database vẫn là nguồn chuẩn; cache stale có policy; không ép dùng thêm database chỉ để đủ công nghệ.

## Nguồn đọc đúng phần

- [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html): Tables, queries, joins, aggregate, foreign key và transaction.
- [Redis Quick Starts](https://redis.io/docs/latest/develop/get-started/): Key-value và thao tác client cơ bản; dùng để học NoSQL/cache.
