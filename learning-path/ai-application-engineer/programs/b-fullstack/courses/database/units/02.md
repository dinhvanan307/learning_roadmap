# B1 · Unit 2 · Transaction và ORM

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

ACID; isolation; race condition; optimistic locking; migration; ORM session; N+1.

## Bài thực hành

Hai session cùng sửa lịch; thêm version check; chạy migration giữ dữ liệu cũ; xem SQL ORM tạo ra.

## Output cần nộp

Timeline, migration và integration report.

## Tiêu chí kiểm tra

Xung đột báo rõ; lỗi giữa transaction rollback đầy đủ; không khẳng định ORM tự ngăn mọi race.

## Nguồn đọc đúng phần

- [PostgreSQL Transaction Isolation](https://www.postgresql.org/docs/current/transaction-iso.html): Read Committed và hành vi khi cập nhật đồng thời.
- [SQLAlchemy Unified Tutorial](https://docs.sqlalchemy.org/en/20/tutorial/): Engine, transaction, ORM mapping, session và query.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
