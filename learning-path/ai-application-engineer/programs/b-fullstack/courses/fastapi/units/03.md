# B2 · Unit 3 · Giao tiếp và lỗi mạng

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

timeout; retry/backoff; connection pool; pagination; SSE/WebSocket; GraphQL schema.

## Bài thực hành

Giả lập provider chậm; stream có hủy; phân trang ổn định; đọc một schema GraphQL để so sánh REST, chưa cần xây hai API.

## Output cần nộp

Demo stream, test timeout/cancel và bảng lựa chọn giao tiếp.

## Tiêu chí kiểm tra

Không retry vô hạn; đóng stream giải phóng tài nguyên; GraphQL là mục nhận biết/mở rộng.

## Nguồn đọc đúng phần

- [Python asyncio Tasks](https://docs.python.org/3/library/asyncio-task.html): Coroutine, task, TaskGroup, timeout và cancellation.
- [MDN HTTP Overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview): Request/response, header, stateless và cookies.
- [GraphQL Learn](https://graphql.org/learn/): Schema, query, mutation; so sánh với REST.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
