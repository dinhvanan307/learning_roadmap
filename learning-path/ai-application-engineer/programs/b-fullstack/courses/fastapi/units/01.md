# B2 · Unit 1 · HTTP và contract

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

DNS; TCP/TLS; port; process; HTTP methods/status; headers; REST; OpenAPI.

## Bài thực hành

Viết contract create/list/get trip; dùng curl kiểm thành công, thiếu trường, không tồn tại và payload sai.

## Output cần nộp

API spec, curl examples và test contract.

## Tiêu chí kiểm tra

Lỗi client khác lỗi server; response schema nhất quán; giải thích được một request qua từng tầng.

## Nguồn đọc đúng phần

- [MDN HTTP Overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview): Request/response, header, stateless và cookies.
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
