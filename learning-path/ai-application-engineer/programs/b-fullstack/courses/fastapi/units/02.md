# B2 · Unit 2 · Auth và persistence

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

authentication/authorization; session/token; object-level access; ORM; DI; idempotency.

## Bài thực hành

Thêm hai user giả lập, API lưu DB; chặn truy cập trip người khác; xử lý cùng request key gửi lặp.

## Output cần nộp

Ma trận quyền và positive/negative API tests.

## Tiêu chí kiểm tra

Không tin user_id do client tự gửi; cùng key khác body bị từ chối; transaction không cộng lặp effect.

## Nguồn đọc đúng phần

- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.
- [SQLAlchemy Unified Tutorial](https://docs.sqlalchemy.org/en/20/tutorial/): Engine, transaction, ORM mapping, session và query.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
