# B3 · Unit 1 · React và trạng thái

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

HTML semantic/form; CSS box model/Flexbox/Grid/responsive; JavaScript function/array/object/module; Promise/async/await/fetch; TypeScript type/interface/union/narrowing; component; props/state; useState/useEffect/useRef; controlled form; keys.

## Nền tảng trước React

Hoàn thành [B.4 · Ngôn ngữ và nền tảng Web](../../../../../../../ROADMAP.md#b-4): tạo form HTML/JavaScript nhỏ gọi API, có label, kiểm input và hiển thị lỗi. Giải thích DOM/event, request và dữ liệu trả về. Viết type cho response và xử lý trường thiếu; không coi type annotation là validation lúc chạy.

Nếu đã có artifact tương đương, dùng để review và chuyển sang React. Nếu chưa có nền tảng, bổ sung thời gian học sau đối chiếu đầu vào; khoảng giờ của course không mặc định đủ để học frontend từ số không.

## Bài thực hành

Chuyển form trip và danh sách item sang React; tách state tối thiểu; không gọi side effect trong render. Giải thích khi nào dùng effect/ref, dependency và cleanup; giữ label và thao tác bàn phím hoạt động.

## Output cần nộp

Component và các trạng thái UI có dữ liệu fixture.

## Tiêu chí kiểm tra

Form kiểm trường; key ổn định; cập nhật state không sửa trực tiếp object đang dùng. Có loading/error khi gọi API; giải thích cleanup của side effect và kiểm lại bằng bàn phím.

## Nguồn đọc đúng phần

- [MDN Structuring content](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content): HTML semantic, cấu trúc nội dung và nền accessibility; theo mục CSS trong lộ trình MDN để ôn layout.
- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide): Control flow, functions, collections, objects, promises và modules.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html): Everyday types, narrowing, functions và object types sau nền JavaScript.
- [React Learn](https://react.dev/learn): Component, props, event và state.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
