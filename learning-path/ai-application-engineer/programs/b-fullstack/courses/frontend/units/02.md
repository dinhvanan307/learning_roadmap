# B3 · Unit 2 · Next.js và API

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

routing/layout; Server/Client Components; data fetching; SSR/CSR; hydration; auth boundary.

## Bài thực hành

Nối trang list/detail vào API; kiểm đăng nhập và quyền ở server/API; hiển thị lỗi có thể thử lại.

## Output cần nộp

Luồng UI → API → DB và sơ đồ nơi code chạy.

## Tiêu chí kiểm tra

Secret không vào client bundle; refresh vẫn đúng; ẩn nút không thay thế kiểm quyền API.

## Nguồn đọc đúng phần

- [Next.js App Router](https://nextjs.org/docs/app/getting-started): Layouts/pages, Server/Client Components, fetching và rendering.
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
