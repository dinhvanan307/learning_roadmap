# C2 · Unit 2 · Quy trình có AI

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

Spec-driven Development; AWS AI-DLC; backlog; Sprint Goal; Definition of Done.

## Bài thực hành

So sánh một vòng làm feature thông thường với gợi ý Spec Kit/AI-DLC; chọn quy trình nhỏ và ghi điểm con người review.

## Output cần nộp

Sơ đồ spec → plan → implement → test → review.

## Tiêu chí kiểm tra

Dùng ý tưởng phù hợp đội nhỏ; không tự tạo đầy đủ vai trò Scrum hay cài toolkit chỉ để theo sơ đồ.

## Nguồn đọc đúng phần

- [GitHub Spec Kit](https://github.com/github/spec-kit): Specification, planning và workflow thực thi có review.
- [AWS AI-DLC](https://aws.amazon.com/blogs/devops/ai-driven-development-life-cycle/): Cách AWS tổ chức phát triển phần mềm có AI và con người review.
- [Scrum Guide](https://scrumguides.org/scrum-guide.html): Product/Sprint Goal, backlog, Increment và Definition of Done.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
