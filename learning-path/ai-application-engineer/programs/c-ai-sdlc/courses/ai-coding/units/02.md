# C1 · Unit 2 · Memory, skill và hook

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

persistent memory; reusable skill; tool; lifecycle hook; permission.

## Bài thực hành

So sánh ghi chú lưu lâu dài, hướng dẫn review tái sử dụng và hook chạy kiểm tra sau thay đổi bằng ví dụ trên công cụ đang dùng.

## Output cần nộp

Bảng phân biệt sáu concept và một quy trình review có thể làm thủ công.

## Tiêu chí kiểm tra

Skill không phải fine-tuning; hook không phải React Hook; cơ chế cụ thể phụ thuộc công cụ, không giả định mọi agent giống nhau.

## Nguồn đọc đúng phần

- [Claude Code Skills](https://code.claude.com/docs/en/skills): Một ví dụ triển khai skill; không phải khái niệm model weight.
- [Claude Code Hooks](https://code.claude.com/docs/en/hooks): Event và hook lifecycle; ví dụ triển khai phụ thuộc công cụ.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
