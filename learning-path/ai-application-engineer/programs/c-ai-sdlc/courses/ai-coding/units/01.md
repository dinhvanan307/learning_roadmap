# C1 · Unit 1 · Prompt và context

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

instruction; prompt; context window; example; retrieved context; context budget.

## Bài thực hành

Viết yêu cầu thêm kiểm ngân sách lịch trình; gửi contract, file liên quan, ví dụ đúng/sai và giới hạn được sửa.

## Output cần nộp

Prompt và bảng thông tin cần/không cần cung cấp.

## Tiêu chí kiểm tra

Không đưa toàn repo theo thói quen; đầu ra AI phải đối chiếu contract, không coi câu trả lời tự tin là bằng chứng.

## Nguồn đọc đúng phần

- [Anthropic Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents): Workflow, agent, tool và kiểm soát độ phức tạp.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
