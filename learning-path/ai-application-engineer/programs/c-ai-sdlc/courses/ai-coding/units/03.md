# C1 · Unit 3 · Review và sửa code AI

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

diff review; test oracle; negative test; regression; provenance; human-in-the-loop.

## Bài thực hành

Yêu cầu AI sửa một hàm; dùng fixture độc lập tìm lỗi biên; tự sửa và chạy lại test, ghi rõ ai làm phần nào.

## Output cần nộp

Diff trước/sau, test fail/pass và nhật ký hỗ trợ.

## Tiêu chí kiểm tra

Tự giải thích nguyên nhân; làm một biến thể mới; không chỉ chạy test do AI viết cùng lời giải.

## Nguồn đọc đúng phần

- [pytest Get Started](https://docs.pytest.org/en/stable/getting-started.html): assert, exception, fixture và cách chạy test.
- [GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow): Branch, commit, pull request, review và merge.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
