# Running project · AI trong quy trình phát triển phần mềm

[Chương trình](../README.md) · [Dự án xuyên suốt](../../../../../projects/RUNNING_PROJECT.md)

## Mục tiêu và output

Một thay đổi trên web được thực hiện từ spec đến review, với nhật ký đóng góp AI và kiểm chứng.

Đây là đầu ra cần thực hiện, chưa phải sản phẩm đã có mã hoặc đã chạy. Có thể giữ code ở repo bài tập riêng và ghi commit trong bằng chứng.

## Năng lực được đánh giá

| PLO | Bằng chứng cần nộp |
| --- | --- |
| PLO1 · Phân biệt instruction, prompt, context, memory, skill và hook trong công cụ lập trình có AI. | Sơ đồ hoặc giải thích kèm ví dụ cụ thể, chỉ ra input/output và ranh giới. |
| PLO2 · Chuyển yêu cầu thành spec, acceptance criteria và kế hoạch thực hiện kiểm tra được. | Artifact chạy được, README và commit tương ứng. |
| PLO3 · Review code AI tạo, phát hiện lỗi và chạy lại kiểm tra sau khi sửa. | Test/report cho ca đúng, ca lỗi và giới hạn kết luận. |
| PLO4 · Quản lý thay đổi bằng Git/PR và mô tả đúng vai trò của con người trong quyết định. | Demo, một biến thể mới, lý do thiết kế và ghi rõ mức trợ giúp. |

## Nghiệm thu

Có yêu cầu, acceptance tests, diff, bug note và kết quả retest; người học giải thích và sửa được code AI tạo.

Ghi môi trường, input, lệnh chạy, expected/actual, commit, lỗi còn lại, người review và quyết định tiếp tục/bổ sung. Một artifact có thể chứng minh nhiều CLO/PLO, nhưng phải chỉ rõ phần nào hỗ trợ kết luận nào.
