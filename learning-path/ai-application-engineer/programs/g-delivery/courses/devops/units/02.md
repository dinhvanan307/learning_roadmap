# G1 · Unit 2 · CI/CD và cloud

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

workflow; build artifact; immutable version; staging; secret; cloud compute/storage/IAM; IaC plan/state.

## Bài thực hành

Chọn một nhà cung cấp hoặc máy lab; lập pipeline test/build/deploy và kế hoạch hạ tầng tối thiểu.

## Output cần nộp

Workflow, deployment config và ADR target.

## Tiêu chí kiểm tra

Không cần học cả AWS/Azure/GCP cùng lúc; ghi tài nguyên/chi phí dự kiến và dọn tài nguyên khi lab kết thúc.

## Nguồn đọc đúng phần

- [GitHub Actions](https://docs.github.com/en/actions/get-started/understand-github-actions): Workflow, event, job, step, runner và artifact.
- [Terraform Introduction](https://developer.hashicorp.com/terraform/intro): Infrastructure as Code và vòng write/plan/apply.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
