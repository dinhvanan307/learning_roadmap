## Program Learning Outcomes

Sau chương trình, người học có thể:

- **PLO1:** Giải thích mô hình dữ liệu, scope, iteration và cách tổ chức chương trình Python.
- **PLO2:** Xây công cụ nhập, kiểm tra và tổng hợp dữ liệu có cấu trúc.
- **PLO3:** Kiểm chứng dữ liệu lỗi, trường hợp biên và hành vi bất đồng bộ bằng kết quả chạy.
- **PLO4:** Giải thích code tự viết hoặc AI hỗ trợ, sửa được một yêu cầu mới mà không phá contract.

## Running project

CLI và báo cáo dữ liệu địa điểm: đọc CSV/JSON, valid/reject theo dòng, thống kê và biểu đồ.

Chi tiết: [mốc sản phẩm và tiêu chí nghiệm thu](running-project/README.md).

## Gate kết thúc

Chạy lại trên fixture mới; input = accepted + rejected; không sửa file gốc; test phát hiện ít nhất hai lỗi được cài có chủ đích.

Mỗi PLO cần liên kết tới bài làm, kết quả chạy và phần giải thích. Dùng [mẫu review](../../../../templates/REVIEW.md); chưa có bài làm thì không đánh dấu đạt.
