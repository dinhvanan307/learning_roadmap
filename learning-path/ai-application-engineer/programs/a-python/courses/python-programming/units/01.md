# A1 · Unit 1 · Dữ liệu và contract

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

list/dict/set; mutability; equality/identity; hàm; exception; type hint.

## Bài thực hành

Viết normalize_places(rows): ID không rỗng/trùng, giá không âm, bool không được coi là giá số. Không sửa input.

## Output cần nộp

Hàm, bảng input/expected và tests cho dữ liệu hợp lệ/lỗi.

## Tiêu chí kiểm tra

List rỗng có kết quả xác định; dữ liệu sai báo lỗi đúng vị trí; bỏ một validation phải làm test fail.

- [Python Classes](https://docs.python.org/3/tutorial/classes.html): Names/objects, scope, class/instance, iterator và generator.
- [pytest Get Started](https://docs.pytest.org/en/stable/getting-started.html): assert, exception, fixture và cách chạy test.

- [Python Data Structures](https://docs.python.org/3/tutorial/datastructures.html): List, dict, set, comprehension và iteration.
- [Python typing](https://docs.python.org/3/library/typing.html): Type annotations và các công cụ hỗ trợ kiểm kiểu.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
