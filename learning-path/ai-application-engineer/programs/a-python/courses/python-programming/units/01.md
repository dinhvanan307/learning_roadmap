# A1 · Unit 1 · Dữ liệu và contract

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

Kiểu dữ liệu và toán tử; if/else, for/while; list/tuple/dict/set; indexing/slicing; comprehension; mutability; equality/identity; hàm và scope; exception; type hint; file CSV/JSON và encoding.

## Chuẩn bị nền tảng

Đối chiếu [A.1 Python nền tảng](../../../../../../../ROADMAP.md#a-1). Nếu đã có bài tương đương, giải thích và chạy lại để review. Nếu còn thiếu, viết các ví dụ nhỏ về hàm, cấu trúc dữ liệu và đọc file trước bài chính. Tạo virtual environment, ghi dependency/phiên bản và lệnh chạy; dùng Git để xem diff và lưu commit từ đầu, theo [A.4](../../../../../../../ROADMAP.md#a-4).

## Bài thực hành

Viết normalize_places(rows): ID không rỗng/trùng, giá không âm, bool không được coi là giá số. Không sửa input.

## Output cần nộp

Hàm, bảng input/expected và tests cho dữ liệu hợp lệ/lỗi.

## Tiêu chí kiểm tra

List rỗng có kết quả xác định; dữ liệu sai báo lỗi đúng vị trí; bỏ một validation phải làm test fail.
