## Topics cần học

Class/object; instance/class attribute; constructor/method; inheritance/composition; module/package; scope/closure; iterator/generator; decorator; context manager; dataclass; type hints.

## Bài thực hành

Tách reader, validator và reporter; đọc file bằng generator; dùng context manager; viết một decorator đo thời gian và giải thích trade-off.

## Output cần nộp

CLI, README chạy lại và commit refactor.

## Tiêu chí kiểm tra
