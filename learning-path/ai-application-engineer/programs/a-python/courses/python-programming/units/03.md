# A1 · Unit 3 · Async và kiểm chứng

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

coroutine/task; event loop; I/O-bound/CPU-bound; timeout; cancellation; concurrency limit.

## Bài thực hành

So sánh đọc metadata giả lập tuần tự và đồng thời; giới hạn số request đang chạy; cài một tác vụ lỗi và một tác vụ chậm.

## Output cần nộp

Timeline, tests và giải thích khi nào async không giúp.

## Tiêu chí kiểm tra

Timeout không để task chạy vô hạn; giữ giới hạn đồng thời; không dùng tác vụ CPU blocking để chứng minh tăng tốc I/O.

## Nguồn đọc đúng phần

- [Python asyncio Tasks](https://docs.python.org/3/library/asyncio-task.html): Coroutine, task, TaskGroup, timeout và cancellation.
- [pytest Get Started](https://docs.pytest.org/en/stable/getting-started.html): assert, exception, fixture và cách chạy test.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
