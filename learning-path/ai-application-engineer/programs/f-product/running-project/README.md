# Running project · Xây dựng sản phẩm và Ownership

[Chương trình](../README.md) · [Dự án xuyên suốt](../../../../../projects/RUNNING_PROJECT.md)

## Mục tiêu và output

MVP có một luồng hoàn chỉnh và bộ bài nộp gồm demo, tests, ADR, README.

Đây là đầu ra cần thực hiện, chưa phải sản phẩm đã có mã hoặc đã chạy. Có thể giữ code ở repo bài tập riêng và ghi commit trong bằng chứng.

## Năng lực được đánh giá

| PLO | Bằng chứng cần nộp |
| --- | --- |
| PLO1 · Chuyển phạm vi được chọn thành backlog và luồng người dùng có thể nghiệm thu. | Sơ đồ hoặc giải thích kèm ví dụ cụ thể, chỉ ra input/output và ranh giới. |
| PLO2 · Tích hợp frontend, backend, dữ liệu và AI thành một MVP nhất quán. | Artifact chạy được, README và commit tương ứng. |
| PLO3 · Kiểm thử luồng chính, quyền, lỗi và regression từ đầu đến cuối. | Test/report cho ca đúng, ca lỗi và giới hạn kết luận. |
| PLO4 · Nhận feedback, sửa lỗi và bàn giao tài liệu có thể dùng lại. | Demo, một biến thể mới, lý do thiết kế và ghi rõ mức trợ giúp. |

## Nghiệm thu

Người khác thực hiện task từ README; critical path và negative tests đạt; quyết định giữ/bỏ feature dựa trên kết quả review.

Ghi môi trường, input, lệnh chạy, expected/actual, commit, lỗi còn lại, người review và quyết định tiếp tục/bổ sung. Một artifact có thể chứng minh nhiều CLO/PLO, nhưng phải chỉ rõ phần nào hỗ trợ kết luận nào.
