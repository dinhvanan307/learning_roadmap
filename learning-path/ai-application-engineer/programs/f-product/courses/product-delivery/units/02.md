# F1 · Unit 2 · Tích hợp end-to-end

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

contract test; E2E; authorization; validation; fallback; feature config.

## Bài thực hành

Nối UI/API/DB/retrieval; giả lập provider lỗi và dữ liệu thiếu; kiểm quyền từ UI lẫn API.

## Output cần nộp

Demo, E2E report và artifact release candidate.

## Tiêu chí kiểm tra

Không chỉ test happy path; lỗi có trạng thái phục hồi; số liệu/budget do code xác định kiểm tra.

## Nguồn đọc đúng phần

- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.
- [React Learn](https://react.dev/learn): Component, props, event và state.
- [OWASP LLM Applications](https://owasp.org/projects/top-10-for-large-language-model-applications): Nhóm rủi ro ứng dụng LLM để lập threat model.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
