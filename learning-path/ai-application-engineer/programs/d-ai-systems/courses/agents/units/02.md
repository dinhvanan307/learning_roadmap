# D3 · Unit 2 · State và hành động

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

state machine; checkpoint; resume; idempotency; HITL; least privilege; audit trail.

## Bài thực hành

Tạm dừng trước thao tác ghi lịch; thử kill/restart rồi resume; xác nhận người dùng gắn đúng payload được duyệt.

## Output cần nộp

State diagram và fault/approval tests.

## Tiêu chí kiểm tra

Resume không lặp effect đã commit; payload đổi phải review lại; học multi-agent sau khi single-agent baseline đủ rõ.

## Nguồn đọc đúng phần

- [Anthropic Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents): Workflow, agent, tool và kiểm soát độ phức tạp.
- [Celery Tasks](https://docs.celeryq.dev/en/stable/userguide/tasks.html): Idempotence, acknowledgement, retry và lỗi task.
- [OWASP LLM Applications](https://owasp.org/projects/top-10-for-large-language-model-applications): Nhóm rủi ro ứng dụng LLM để lập threat model.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
