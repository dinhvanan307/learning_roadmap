# D3 · Unit 3 · MCP và đo hiệu quả

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

MCP host/client/server; tools/resources/prompts; auth boundary; protocol; task success.

## Bài thực hành

Tạo MCP tool tra cứu dữ liệu read-only hoặc mock server; so sánh cùng nhiệm vụ bằng API trực tiếp, workflow và agent.

## Output cần nộp

Tool contract, integration report và bảng so sánh.

## Tiêu chí kiểm tra

MCP không tự giải quyết authorization; ghi thất bại/chi phí; không mặc định nhiều agent tốt hơn.

## Nguồn đọc đúng phần

- [MCP Architecture](https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture): Host/client/server và bề mặt tool/resource/prompt.
- [Anthropic Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents): Workflow, agent, tool và kiểm soát độ phức tạp.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
