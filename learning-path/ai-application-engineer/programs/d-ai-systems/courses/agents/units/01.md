# D3 · Unit 1 · Loop và harness

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

observe/decide/act; workflow vs agent; harness; tool schema; stop condition.

## Bài thực hành

Viết vòng gọi model → validate tool args → thực thi mock tool → quan sát; giới hạn số lần gọi và thời gian.

## Output cần nộp

Agent nhỏ và trace một nhiệm vụ nhiều bước.

## Tiêu chí kiểm tra

Không vòng lặp vô hạn; unknown tool/args sai bị chặn; kết quả tool là dữ liệu không tự tạo quyền.

## Nguồn đọc đúng phần

- [Anthropic Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents): Workflow, agent, tool và kiểm soát độ phức tạp.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
