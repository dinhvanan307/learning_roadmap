# D1 · Unit 1 · Model và biểu diễn

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

tokenization; vector/cosine; attention; Transformer; encoder; decoder; pretraining/inference.

## Bài thực hành

Vẽ luồng input → token → model → output; giải thích embedding model và generative model phục vụ hai mục đích khác nhau.

## Output cần nộp

Sơ đồ và ví dụ tính cosine trên vector nhỏ.

## Tiêu chí kiểm tra

Không khẳng định mọi LLM có đủ encoder lẫn decoder; phân biệt context và cập nhật model weights.

## Nguồn đọc đúng phần

- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/en/chapter1/1): Transformer models và các phần nhập môn LLM.
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762): Kiến trúc Transformer gốc; không đại diện mọi LLM hiện nay.
- [NumPy Basics](https://numpy.org/doc/stable/user/absolute_beginners.html): ndarray, shape, dtype, axis, indexing và view/copy.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
