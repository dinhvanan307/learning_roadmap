# D1 · Unit 2 · Provider adapter

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

prompt/messages; structured output; schema validation; timeout; fallback; rate limit.

## Bài thực hành

Trích thông tin địa điểm vào schema; fake provider trả JSON sai, timeout, lỗi tạm thời; sau đó mới thử provider thật nếu có ngân sách.

## Output cần nộp

Adapter và contract tests; config mẫu không secret.

## Tiêu chí kiểm tra

Schema hợp lệ chưa chắc đúng nội dung; ghi nguồn field và cách xử lý trường thiếu; không đổi provider làm mất contract.

## Nguồn đọc đúng phần

- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.
- [Python asyncio Tasks](https://docs.python.org/3/library/asyncio-task.html): Coroutine, task, TaskGroup, timeout và cancellation.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.
