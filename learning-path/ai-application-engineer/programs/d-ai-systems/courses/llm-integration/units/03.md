# D1 · Unit 3 · Đánh giá tích hợp

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

baseline; dev/test; exact match/rubric; p50/p95; token usage; cost; model version.

## Bài thực hành

So sánh parser/rule hoặc cấu hình đơn giản với model trên tập fixture được chốt trước; tính chất lượng, lỗi và chi phí.

## Output cần nộp

Model-selection report và dữ liệu có version.

## Tiêu chí kiểm tra

Cùng input/rubric, không chỉnh prompt trên test; ghi sample size và trường hợp model thua baseline.

## Nguồn đọc đúng phần

- [scikit-learn Common Pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): Preprocessing, leakage, pipeline và randomness.
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/en/chapter1/1): Transformer models và các phần nhập môn LLM.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
