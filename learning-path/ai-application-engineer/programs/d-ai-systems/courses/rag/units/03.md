# D2 · Unit 3 · Sinh câu trả lời và kiểm chứng

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

grounding; citation; supported claim; abstention; stale evidence; context budget; prompt injection.

## Bài thực hành

Trả lời câu hỏi từ corpus; thử ca đủ/thiếu/mâu thuẫn nguồn và nguồn chứa chỉ dẫn độc hại.

## Output cần nộp

Answer rubric, citation span và error analysis.

## Tiêu chí kiểm tra

Có citation chưa đủ: đoạn trích phải hỗ trợ claim; thiếu nguồn thì nêu thiếu/không kết luận; đo retrieval và generation riêng.

## Nguồn đọc đúng phần

- [Microsoft RAG Overview](https://learn.microsoft.com/en-us/azure/search/retrieval-augmented-generation-overview): Retrieval, grounding, ingestion và hệ thống RAG.
- [OWASP LLM Applications](https://owasp.org/projects/top-10-for-large-language-model-applications): Nhóm rủi ro ứng dụng LLM để lập threat model.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
