# ML · Machine Learning Foundations

[Learning path](../../README.md) · [Tiến độ](../../../../PROGRESS.md)

**Vai trò:** nhánh mở rộng, không bắt buộc cho mọi ứng dụng AI. **Đầu vào:** A2; học khi muốn đi sâu model hoặc khi giả thuyết dự án yêu cầu.

## Program Learning Outcomes

Sau chương trình, người học có thể:

- **PLO1:** Giải thích vector, xác suất, loss và mục tiêu tối ưu trong một bài toán nhỏ.
- **PLO2:** Tạo baseline và pipeline học máy từ dữ liệu có nhãn.
- **PLO3:** Đánh giá không leakage, phân tích lỗi và so sánh với giải pháp đơn giản.
- **PLO4:** Giải thích lựa chọn feature/model và đóng gói inference có contract.

## Courses và khối lượng

| Course | Giờ dự kiến | Milestone |
| --- | ---: | --- |
| [ML1 · Math for Machine Learning](courses/math/README.md) | 20–35 | Dùng thống kê/xác suất mô tả phân bố và độ bất định trong mẫu. |
| [ML2 · Machine Learning và Evaluation](courses/classical-ml/README.md) | 30–45 | Xây pipeline preprocessing và model baseline bằng scikit-learn. |

**Tổng tham chiếu:** 50–80 giờ, gồm đọc, thực hành, test và review. Đây là ước lượng thiết kế mới, cần điều chỉnh theo bài làm đầu vào; không phải số giờ do mindmap xác nhận.

## Running project

Mô hình phân loại dữ liệu mẫu công khai hoặc tổng hợp, kèm model card và evaluation.

Chi tiết: [mốc sản phẩm và tiêu chí nghiệm thu](running-project/README.md).

## Gate kết thúc

Split cố định; preprocessing fit trên train; baseline và candidate đo trên cùng test; lưu model/config/version.

Mỗi PLO cần liên kết tới bài làm, kết quả chạy và phần giải thích. Dùng [mẫu review](../../../../templates/REVIEW.md); chưa có bài làm thì không đánh dấu đạt.
