# ML2 · Unit 3 · Đóng gói và giải thích

[Course](../README.md) · [Concept thường dùng](../../../../../../../docs/CONCEPTS.md)

## Topics cần học

confusion matrix; threshold; error analysis; model card; inference contract.

## Bài thực hành

Tạo CLI/API inference; phân tích false positives/negatives và data shift giả lập.

## Output cần nộp

Model card, prediction tests và báo cáo test cuối.

## Tiêu chí kiểm tra

Chưa tốt hơn baseline vẫn báo thật; không chỉ dùng accuracy khi nhóm lệch.

## Nguồn đọc đúng phần

- [scikit-learn Common Pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): Preprocessing, leakage, pipeline và randomness.
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/): Request/response model, dependencies, errors, security và testing.

## Tự giải thích

Nêu input/output, một quyết định kỹ thuật và một ca lỗi. Chỉ ra dòng code hoặc bước xử lý liên quan; thử một thay đổi nhỏ so với bài đã làm. Ghi phần tự viết và phần được hướng dẫn/AI hỗ trợ.

Đánh dấu tiến độ bằng [mẫu review](../../../../../../../templates/REVIEW.md). Đây là đề bài/lộ trình; chưa có lời giải hoặc kết quả test của người học.
