# Running project · Nghiên cứu và lựa chọn dự án

[Chương trình](../README.md) · [Dự án xuyên suốt](../../../../../projects/RUNNING_PROJECT.md)

## Mục tiêu và output

Project brief, evidence matrix và báo cáo thử nghiệm quyết định phạm vi sản phẩm.

Đây là đầu ra cần thực hiện, chưa phải sản phẩm đã có mã hoặc đã chạy. Có thể giữ code ở repo bài tập riêng và ghi commit trong bằng chứng.

## Năng lực được đánh giá

| PLO | Bằng chứng cần nộp |
| --- | --- |
| PLO1 · Xác định người dùng, nhiệm vụ, ràng buộc và hiện trạng có nguồn. | Sơ đồ hoặc giải thích kèm ví dụ cụ thể, chỉ ra input/output và ranh giới. |
| PLO2 · Đặt giả thuyết có thể bị bác bỏ và thiết kế so sánh công bằng. | Artifact chạy được, README và commit tương ứng. |
| PLO3 · Phân tích số liệu cùng lỗi/giới hạn để ra quyết định. | Test/report cho ca đúng, ca lỗi và giới hạn kết luận. |
| PLO4 · Chọn phạm vi dự án và điều kiện tiếp tục/dừng trước khi phát triển MVP. | Demo, một biến thể mới, lý do thiết kế và ghi rõ mức trợ giúp. |

## Nghiệm thu

Có bài toán, nguồn dữ liệu, baseline, phép đo, kết quả hoặc UNKNOWN; quyết định không dựa riêng vào demo đẹp.

Ghi môi trường, input, lệnh chạy, expected/actual, commit, lỗi còn lại, người review và quyết định tiếp tục/bổ sung. Một artifact có thể chứng minh nhiều CLO/PLO, nhưng phải chỉ rõ phần nào hỗ trợ kết luận nào.
