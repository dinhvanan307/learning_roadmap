# Bằng chứng học tập

Lưu nhật ký và báo cáo đủ để mở lại bài làm, chạy lại kiểm tra và hiểu kết luận review. Repo hiện chưa có bài nộp được xác nhận.

## Cách lưu

1. Copy [mẫu review](../templates/WEEKLY_REVIEW.md) vào thư mục của tuần, chẳng hạn `W00/2026-10-07.md`.
2. Điền file hoặc URL của repo bài tập, commit, lệnh chạy, kết quả đúng/lỗi và mức trợ giúp.
3. Thêm link tới nhật ký trong [PROGRESS.md](../PROGRESS.md).

Code có thể ở repo khác; cần trỏ đến commit cụ thể khi dùng làm bằng chứng. Ảnh chụp là bổ sung, không thay thế lệnh và kết quả có thể chạy lại.

## Khi chia sẻ

Chỉ commit dữ liệu và log được phép chia sẻ. Xóa token, API key và dữ liệu cá nhân khỏi báo cáo trước khi đưa lên GitHub. `evidence/private/` được bỏ qua bởi `.gitignore` để giữ ghi chú cục bộ; liên kết đến đó không dùng làm bằng chứng mà người khác có thể review.
